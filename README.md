# Python Practice & Problem Solving

## 🛠️ Concepts Practised
* **In-Place Mutation vs. Pure Functions:** Learning how Python handles memory and data modification (such as list manipulation methods).
* **Slicing Mechanisms:** Implementing performance-efficient sequence reversals using Python's `[::-1]` matrix notation.
* **Algorithmic Optimisation:** Refactoring multi-layered loops (like nested search-and-replace text functions) into clean, readable code blocks.
